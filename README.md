# Rua 10 — Futebol de Rua (nome provisório)

Jogo 3D de futebol de rua para Android feito em **Godot 4.3**: pelada 3 contra 3 numa
rua de bairro brasileira, com traves de ferro, adolescentes assistindo e esperando a vez,
roupas sujas e dribles naturais.
